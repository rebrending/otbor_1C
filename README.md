# Дневник обещаний

**Автор:** Асманов Даниил Владиславович

**Задача:** №5 «Дневник обещаний»

## О проекте

Локальное веб-приложение для создания, редактирования и закрытия дел. Поддерживает просмотр по дням, неделям и месяцам, поиск и комментарии с отметкой времени.

## Проектные решения

- Приложение работает без сервера и не обращается к сети.
- Дела хранятся в IndexedDB отдельными записями. Повреждённая запись пропускается с предупреждением, остальные продолжают работать.
- Черновики форм сохраняются в `localStorage` при вводе и восстанавливаются при повторном открытии карточки.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу `http://localhost:3000`.

Сборка и запуск собранной версии:

```bash
npm run build
npm start
```

Запуск тестов:

```bash
npm test
```

## Директории

- `app/` — интерфейс, стили и локальное хранилище.
- `public/` — статические файлы.
- `tests/` — проверки сборки и основных требований.
- `build/` — служебная настройка сборщика.
- `worker/` — точка входа локального веб-приложения.
- `.openai/` — конфигурация запуска проекта.

## Дополнительная информация

Данные сохраняются в профиле текущего браузера и не попадают в репозиторий. Для очистки данных необходимо удалить хранилище сайта в настройках браузера.
