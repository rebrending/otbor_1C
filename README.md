# Дневник обещаний

Локальное веб-приложение для ведения дел: создание, редактирование, закрытие, просмотр по дням, неделям и месяцам, поиск и комментарии с отметкой времени.

Данные хранятся в IndexedDB браузера, каждое дело — отдельной записью. Черновики форм сохраняются отдельно в `localStorage`. Приложение не обращается к сети.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка сборки и тестов:

```bash
npm test
```

## Директории

- `app/` — интерфейс, стили и локальное хранилище.
- `public/` — статические файлы.
- `tests/` — проверки сборки и основных требований.
- `build/` — служебная настройка сборщика.
- `worker/` — точка входа локального веб-приложения.
- `.openai/` — конфигурация запуска проекта.
